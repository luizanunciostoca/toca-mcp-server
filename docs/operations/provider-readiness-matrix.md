## Interpretation rules

- `credentials present?` means repository-safe evidence only. GitHub source cannot prove a live secret value merely because an environment variable or secret reference exists.
- Never expose token/secret contents.
- `CONNECTED`, `INTEGRATION_VALIDATED` and `PRODUCTION_VALIDATED` require the canonical capability lifecycle evidence; this document does not promote them.
- A provider-neutral interface is not provider connectivity.
- A successful infrastructure/deployment smoke is not the same as a successful provider OAuth/account/scope smoke.
- Internal TOCA components such as the managed scheduler are not evidence that Meta/Instagram provider writes are production validated.
