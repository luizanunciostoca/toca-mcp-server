# Sunset Story runtime fonts

These font files are runtime candidates for the Sunset Story template renderer. The visual references are flattened PNGs, so the system records them as visual-match candidates rather than claiming exact identity. Bodoni Moda is used for aspirational editorial headlines; Montserrat is used for functional text, support, time and CTA. The source templates keep the font identity status explicit until the original editable campaign package is provided.
