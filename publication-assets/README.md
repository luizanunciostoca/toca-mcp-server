# TOCA OS Instagram publication assets

This branch stores only content-addressed, already-approved publication JPEGs for the GitHub-native Instagram publisher.

Each asset must be named `<sha256>.jpg` and accompanied by `<sha256>.json` staging evidence. The staging workflow verifies JPEG magic bytes and exact SHA-256 before commit.

Do not place credentials, signed URLs, drafts, or unapproved media in this branch.
